# Расширение: вишлист одной кнопкой

Кнопка в браузере, которая перезаписывает `games.json` в папке бота полным зеркалом
твоего вишлиста Steam. Добавил игру в вишлист — появится в дайджесте, убрал — исчезнет.

Пароль от Steam, ключ API и двухфакторка не нужны: список читается из уже открытой
сессии в браузере, тем же запросом, что и сниппет из [../docs/get-wishlist.md](../docs/get-wishlist.md).

## Установка

1. Chrome → `chrome://extensions` → включи **Режим разработчика**.
2. **Загрузить распакованное расширение** → укажи папку `extension`.
3. Открой настройки расширения (кнопка «Подробнее» → «Параметры расширения») и нажми
   **Выбрать папку** → укажи папку бота, ту, где лежит `run.bat`.

Третий шаг делается один раз. Chrome запомнит папку, но после перезапуска браузера
может переспросить доступ — это один клик по кнопке в попапе.

## Как пользоваться

Иконка расширения → **Обновить вишлист**. Дальше `run.bat`, и дайджест уйдёт
в Telegram уже по свежему списку.

Открывать вкладку Steam не обязательно: если ни одной нет, расширение само откроет её
в фоне, прочитает вишлист и закроет. Залогиненным в Steam при этом быть надо.

## Что оно пишет и куда

Ровно один файл — `games.json` в выбранной папке, массив appid. Больше ничего в папке
не читается и не меняется. Твоя старая выгрузка `game.json` не тронута: загрузчик бота
предпочитает `games.json`, так что при желании откатиться достаточно удалить его.

## Две защиты от потери списка

Зеркало умеет удалять игры, а значит неудачный запрос мог бы затереть список. Поэтому:

- **пустой вишлист не пишется вообще.** Пустой ответ почти всегда значит «сессия
  отвалилась», а не «ты убрал все игры»;
- **если список внезапно сократился больше чем вдвое**, расширение не пишет молча,
  а показывает «было 418, собралось 12» и отдельную кнопку подтверждения.

## Файлы

```
manifest.json  — права: только store.steampowered.com, scripting и tabs
popup.html/js  — кнопка «Обновить вишлист», запись файла, защита от потери списка
options.html/js— выдача доступа к папке (диалог выбора нельзя открыть из попапа)
store.js       — хранение доступа к папке в IndexedDB и переспрос прав
```

Почему доступ к папке живёт в IndexedDB, а не в `chrome.storage`: `chrome.storage`
хранит только JSON, а доступ к папке — это живой объект `FileSystemDirectoryHandle`.
IndexedDB умеет его сохранять между запусками браузера.
